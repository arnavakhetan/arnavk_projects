# Project Portfolio

This repository contains projects I have built through coursework and independent work as a Data Science student at the University of San Francisco. The projects cover data science, machine learning, algorithms, data structures, and software development.

## Featured Projects

| Project                                                                                              | Description                                                                                                                                                                                | Technologies                               |
| ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------ |
| [College Basketball and NBA Draft Analysis](featured-projects/college-basketball-nba-draft-analysis) | Analyzed NCAA and NBA datasets to identify factors associated with college basketball success and examine how team performance relates to NBA draft outcomes.                              | Python, SQL, Pandas, Data Visualization    |
| [Mount Everest ML Classification](featured-projects/mount-everest-ml-classification)                 | Built a logistic regression model using data from 5,324 Mount Everest climbers to predict climbing outcomes and evaluate model performance beyond overall accuracy.                        | R, Logistic Regression, Data Visualization |
| [Othello-Inspired Strategy Game](featured-projects/othello-strategy-game)                            | Built a strategy-game simulation that compares random, heuristic, and Minimax players across repeated matchups and analyzes strategy performance and first-player advantage.               | Python, Minimax, Game Simulation           |
| [Airbnb Price Prediction](featured-projects/price-prediction-model)                                  | Built and evaluated regression models to predict Airbnb listing prices, using preprocessing and feature engineering to achieve a validation RMSE of approximately 63.85 with a CART model. | Python, Pandas, scikit-learn, CART         |
| [Shortest Path Finder](featured-projects/shortest-path-finder)                                       | Implemented Dijkstra’s algorithm with a custom min-heap to model U.S. cities as a weighted graph and calculate shortest routes.                                                            | Java, Graphs, Algorithms                   |
| [Spell Checker](featured-projects/spell-checker)                                                     | Created a trie-based spell checker that identifies misspelled words, validates prefixes, and suggests possible corrections.                                                                | Java, Tries, Data Structures               |
| [Poker Player](featured-projects/poker-player)                                                       | Developed a socket-based poker client with real-time protocol handling, automated betting decisions, and a test framework for communication and game logic.                                | Java, Socket Programming                   |
| [File Directory System](featured-projects/file-directory-system)                                     | Developed a tree-based virtual file system supporting file creation, navigation, searching, deletion, and recursive directory operations.                                                  | Java, Trees, Data Structures               |
| [Custom Song List](featured-projects/custom-song-list)                                               | Built a linked-list music library supporting song searches, ratings, list merging, and identification of top and bottom performers.                                                        | Java, Linked Lists                         |
| [Maze Solver](featured-projects/maze-solver)                                                         | Implemented a maze solver using the right-hand rule with validation for unsolvable mazes and invalid grid configurations.                                                                  | Java, Algorithms                           |
